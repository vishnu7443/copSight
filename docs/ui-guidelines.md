# UI/UX Design Guidelines

## Visual Aesthetics
- **Color Palette**: Modern 21st-century slate & deep indigo theme (`#0f172a` / `#1e293b` / `#334155`), slate glass panels (`bg-slate-900/80 backdrop-blur-md`), with Karnataka State Police Gold (`#f59e0b`), Cyan (`#06b6d4`), and Crimson alert highlights (`#ef4444`). Avoid plain pitch-black backgrounds.
- **Card & Surface Design**: Subtle border highlights (`border-slate-700/60`), soft inner glow, 21st-century modern component styling, rounded-xl corners, smooth micro-interactions.
- **Typography**: Modern typography stack (`Inter` / `Plus Jakarta Sans` / `Outfit`).

## Key UI Components & Layout
- **Navigation Bar**: Glassmorphic header with police station badge, role indicator switcher, global search, and real-time audit status indicator.
- **Agent Intelligence Console**: Modern split-pane chat & execution inspector with animated step progression (Search -> Summary -> Validation -> Safety), confidence gauge meter, and structured entity pill tags.
- **GIS Map Viewer**: Interactive Leaflet map with custom SVG incident markers, radius spatial search control, crime heatmaps, and slide-over incident drawer.
- **Executive Analytics Dashboard**: Modern KPI cards, trend charts (Recharts), station workload matrix, and crime surge indicators.
- **Audit & Compliance Portal**: Tabular audit trail with IP address, user badge, role, execution duration, and instant CSV export.
