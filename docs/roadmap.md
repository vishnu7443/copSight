# Product Roadmap

## Phase 1: MVP Core (Current Sprint)
- Full stack application with React + TypeScript frontend and FastAPI backend.
- Specialized Agentic AI system (Search, Summary, Trend, Report, Safety, Validation).
- GIS Crime Map with Leaflet incident clustering and heatmaps.
- Role-based authentication (RBAC) & Audit trail log system.
- Realistic Karnataka State Police seed dataset (Bengaluru/Mysuru stations & FIRs).

## Phase 2: Multi-Station Deployment & Advanced Analytics
- Integration with live state police CCTNS data feeds.
- Automated shift handover briefing generation.
- Suspect modus operandi matching across districts.

## Phase 3: Graph Linkage & Offline LLM Deployment
- Neo4j graph database integration for offender-vehicle-location link analysis.
- Air-gapped local LLM deployment (vLLM / Ollama) for high-security police networks.
